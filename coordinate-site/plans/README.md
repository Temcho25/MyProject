Floor plans of block A, taken from api.coordinate.ge (`/api/search` → `2D` / `3D` fields).

- `<pos>-2d.png` — original 2D plan (unchanged PNG from the developer).
- `<pos>-3d.webp` — 3D render, resized to max 2400 px and saved as WebP q90 (originals are 20–33 MB PNGs).
- `<pos>` = apartment position on the floor (apt 1803 → `03`); `ph1` / `ph2` = penthouses on floors 29–30.

Layout data (rooms, area, floors) lives in `LAYOUTS` in ../index.html.
