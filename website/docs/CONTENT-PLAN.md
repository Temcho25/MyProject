# Insta Tour — SEO content plan (first 3 months)

_Last updated: 2026-11-08 · see `docs/SEO-KEYWORDS.md` for keyword sources and limitations._

## Principles
- **Commercial first.** The three tour pages, /tours/ and /custom-tours/ are the money pages. Every article must support one of them.
- **Fewer, better articles.** 2 articles per week is realistic for a small team. One strong guide beats five thin ones.
- **Ship RU + EN together; KA a few days later** after a native Georgian review. Never publish unreviewed machine-translated Georgian.
- **Seasonality.** It is November 2026: the Harbin 2026/27 season starts in late December–January, so winter content goes first.
  For the following seasons, have winter content live by **early September**; Zhangjiajie/Guilin content peaks in spring (Mar–May) and autumn (Sep–Nov) — publish 6–8 weeks ahead.
- Every rule-type fact (visas, payments, prices, schedules, festival dates) gets "as of <month year>" wording and is re-checked when updating.

## Per-article checklist
- [ ] Title 50–60 characters, primary keyword near the start; description 140–160 characters.
- [ ] One H1 (`h1` field), 4–7 `##` sections built from real questions (People also ask).
- [ ] Link to the target tour near the top and in the closing paragraph; link to /custom-tours/ once; link up to the cluster pillar.
- [ ] Cover photo from `src/data/photo-manifest.json` (licensed, correct place) with localized alt text.
- [ ] All three files `ru.md`, `en.md`, `ka.md` with the same slug → hreflang triplet is automatic.
- [ ] `updated` date changed whenever facts are re-checked.
- [ ] No invented prices, hours, statistics or reviews; changeable rules phrased "as of …, check before booking".
- [ ] Where prices are mentioned: "international flights not included".
