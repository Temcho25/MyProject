# Insta Tour — keyword research & page mapping

_Last updated: 2026-11-08_

## Method and limitations (read first)

- **No paid keyword tools were available** (no Ahrefs / Semrush / Google Keyword Planner access).
  So this document contains **no search volumes, keyword difficulty or CPC numbers**.
- "Demand" and "Competition" columns are **qualitative estimates** (high / medium / low) based on:
  live Google results checked with web search (who ranks: aggregators, big operators, blogs),
  the phrasing Google suggests, and general knowledge of the market.
- Observations from the SERP checks (Nov 2026):
  - **RU "тур в Китай из Тбилиси"** — results are almost all flight sellers, not tour operators → low competition, a real gap for Georgia-based Russian speakers.
  - **KA "ტური ჩინეთში"** — practically no Georgian-language China tour pages rank → Georgian pages can win low-competition terms quickly; volumes are small.
  - **EN "small group tour china …"** — crowded with specialist operators and aggregators (TourRadar, TravelChinaGuide, ChinaTours, Wendy Wu, etc.). Their groups are usually 12–16 people, so **"5–7 people" is a genuine differentiator** to put in titles.
  - **RU Харбин** — dominated by excursion marketplaces selling day trips; a multi-city 12-day winter tour is a different product → angle: "Харбин + Пекин + Шаолинь + Сиань в мини-группе".
  - Competitors in Russia often include flights in the price; ours doesn't → handled openly in FAQ and on every tour page.

### How to validate after launch
1. **Google Keyword Planner** (free with a Google Ads account): check RU/EN/KA terms below with locations Georgia, Russia, Kazakhstan, Armenia, UK/US.
2. **Search Console → Performance** after 4–6 weeks: filter by country and page; keep terms that get impressions, rewrite titles where CTR < 2%.
3. Check Google autocomplete and "People also ask" manually in each language once a quarter.
4. Re-check the top-10 results for each primary keyword every 3 months.

Intent codes: **C** commercial · **I** informational · **T** transactional · **N** navigational.

## Cannibalisation rules
1. **Tour page vs guide on the same place** (Harbin, Zhangjiajie): the tour page targets "tour / trip / group"; the guide targets "festival / what to see / how to get there / dates". Guides link to the tour once near the top and once at the end.
2. **/tours/ vs Grand tour**: /tours/ gets the generic "тур в Китай"; the 13-day page gets "13 дней / 2 недели / групповой".
3. **first-trip guide vs FAQ vs group-vs-private**: first-trip = pillar for planning ("what to know"); FAQ = short answers about *our* tours; group-vs-private = only the comparison query.
4. **Trains**: the future "how to buy train tickets" topic should be a section of the existing trains guide, not a new article.
