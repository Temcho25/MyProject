# Brand assets

- `logo.svg`: **add the official Dream Palace logo here** (the green mark with the building
  silhouettes), then set `logo: 'assets/brand/logo.svg'` in `js/config.js`. Until then a
  temporary typographic wordmark is shown. The logo has not been redrawn.
- `favicon.svg`: a neutral placeholder (two block outlines on a datum line). Replace it with
  a favicon made from the official mark.
- `og-image.png`: a 1200×630 social preview rendered from the site's hero. Replace it with
  official imagery when available.

The palette in `css/tokens.css` (forest, emerald, fresh green, gold, graphite, warm white,
concrete) was taken from the creative brief. Check it against the real logo colours and
adjust the tokens if needed.
